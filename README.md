# Время красоты — сайт салона красоты

Сайт салона «Время красоты», Москва, ул. Новаторов, 36, корп. 1. Каждый день 09:00–22:00.

Один файл `index.html` и папка `img/`, сборка не нужна. Открывается двойным кликом или через GitHub Pages.

## Что есть на сайте
- Первый экран с видео (циферблат) и рукописным логотипом салона.
- Примерочная цвета: 8 оттенков лака, при нажатии меняется фото руки.
- Услуги, цены и онлайн-запись: меню с «+», выбор даты на 2 месяца вперёд и времени, контакты, итог визита.
- Работы мастеров с фильтрами и просмотром, мастера, пространство салона, отзывы, карта.
- Адаптив под телефон.

## Заявки
В конце `index.html` в блоке `CONFIG`:
- `tgToken` и `tgChatId` — токен бота от @BotFather и chat_id, тогда заявки приходят в Telegram;
- если пусто — заявка открывается готовым сообщением в WhatsApp салона (`whatsapp`).

## Как выложить на GitHub Pages
Settings → Pages → Branch: `main`, папка `/ (root)` → Save. Через 1–2 минуты сайт откроется по адресу
`https://davydovserg.github.io/studio-time-/`.
